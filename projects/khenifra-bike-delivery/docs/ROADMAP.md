# Roadmap

## Phase 0 — Local validation
- Interview 10 residents
- Interview 10 local businesses
- Recruit 3-5 riders
- Validate acceptable delivery price bands
- Map the busiest pickup/drop-off clusters
- Define rider verification requirements and operating rules

## Phase 1 — Customer request MVP
- Mobile-first request form
- Phone verification
- Pickup / drop-off map pins
- Distance-based quote
- Cash payment
- Order number
- WhatsApp confirmation
- Admin dispatch board

## Phase 2 — Rider app
- Rider login
- Availability toggle
- Nearby jobs
- Accept / decline
- Navigation link
- Pickup confirmation
- Drop-off confirmation
- Delivery PIN
- Earnings view

## Phase 3 — Live operations
- Supabase Realtime
- Customer tracking link
- Rider GPS location while active delivery is in progress
- Notifications
- Ratings
- Incident workflow
- Rider performance metrics

## Phase 4 — Merchant tools
- Saved merchant location
- One-click delivery creation
- Merchant order history
- Monthly invoice / statement
- API or webhook later

## Phase 5 — Marketplace only after demand
- Restaurant/store discovery
- Menus/catalogues
- Promotions
- Search and categories
- Online payments

## Key metrics
- Requests/day
- Completed deliveries/day
- Median assignment time
- Median pickup-to-drop-off time
- Cancellation rate
- Repeat customer rate
- Deliveries/rider/hour
- Revenue/delivery
- Rider payout/delivery
- Contribution margin/delivery
