# Portfolio Control Protocol

Use `/AI_PROJECT_REGISTRY.md` as the first source of truth for selecting a repository.

For every task:
- SELECT: identify the project and canonical repo.
- READ: read the repo's AGENTS.md and .chatgpt/PROJECT_CONTROL.md.
- INSPECT: inspect current state before editing.
- CHANGE: make the smallest safe change.
- VERIFY: check deployment/live behavior when relevant.
- REPORT: distinguish committed, deployed, verified, and still-unverified facts.

Never jump directly from a project name to a repository based only on memory or a similar repo name.
